# 메이플 바

재획하면서 자주 쓰는 알림과 사이트를 메이플 화면 위에 모아 보여 주는 Windows 프로그램입니다.

- 최신 버전: **1.2.2**
- 버전별 바뀐 점: [메이플 바 패치 노트](https://choimy0204.github.io/maplebar/)

## 설치

[설치 파일 받기](https://github.com/choimy0204/maplebar/releases/latest/download/MapleBar-Setup.exe) (`MapleBar-Setup.exe`)

- 받은 파일을 켜면 최신 버전을 깃허브에서 받아 확인한 뒤 설치하고, 끝나면 메이플 바를 켭니다.
- 버전별 설치 파일(`MapleBar-Setup-버전.exe`)은 [Releases](https://github.com/choimy0204/maplebar/releases/latest)에 있습니다.

- Windows 10/11 64비트용입니다.
- 처음 설치할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
- 1.0.8부터는 켤 때 새 버전 안내가 뜨면 [확인]만 누르면 알아서 설치하고 다시 켜집니다.
- 숨긴 바는 **Ctrl+Alt+M**으로 다시 열 수 있습니다.

## 최근 업데이트

**1.2.2** (2026.11.27) · 바 크기 직접 조절 · 야누스 알림 오류 수정
- 바 양 끝을 끌어서 바 크기를 바꿀 수 있습니다. 바꾼 크기는 저장되고, 메이플 해상도가 바뀌어도 그대로 둡니다.
- 야누스를 다시 깔았는데 예전 시간에 맞춰 일찍 알리던 문제를 고쳤습니다.
- 설치 키를 눌러도 가끔 세지 못해 알림이 다시 울리던 문제를 고쳤습니다.

**1.2.15** (2026.11.26) · 자동 실행 켜기 오류 수정
- "PC 켤 때 자동 실행"을 켜면 "자동 실행 설정을 바꾸지 못했어요" 창이 뜨고 켜지지 않던 문제를 고쳤습니다.

**1.2.14** (2026.11.21) · 알림 이름 오류 수정
- 반복 알림의 이름을 바꾸려고 누르면 오류 창이 뜨던 문제를 고쳤습니다.

**1.2.13** (2026.11.21) · 검색 목록 안정화
- 설정 같은 바의 버튼을 누를 때 최근 검색 목록이 떴다 사라지던 문제를 고쳤습니다. 이제 검색칸을 누르거나 글자를 칠 때만 펼쳐집니다.
- 목록 위에 마우스가 있어도 엔터를 치면 친 이름으로 검색합니다.
- 바가 움직여도 목록이 따라옵니다.

**1.2.12** (2026.11.21) · 알림 설정 칸 정리
- 알림 설정 1페이지에서 알림 소리 칸을 넓히고 알림 방식 칸을 줄였습니다.
- 소리 크기 글자가 버튼과 겹치던 문제를 고쳤습니다.

**1.2.11** (2026.11.20) · 알림 설정 3페이지 · 알림음 끄기
- 알림 소리 칸에 **알림음** 스위치가 생겼습니다. 끄고 제목 읽어 주기만 켜면 목소리만 들립니다.
- 알림 설정이 길어져 세 페이지로 나눴습니다. 3페이지에 00시 알림과 알림 띄울 모니터가 있습니다.
- 00시 알림 문구를 "10분 뒤 초기화 됩니다"처럼 바꿨습니다.
- 켜 둔 채로 새 버전이 나왔을 때 안내가 늦게 뜨던 문제를 고쳤습니다.

**1.2.1** (2026.11.20) · 00시 알림 · 알림 읽어 주기 · 세로로 놓기
- 알림창 2쪽에 **00시 알림**이 생겼습니다. 00시 몇 분 전에 알려 줄지 정할 수 있습니다.
- **제목 읽어 주기**를 켜면 알림음 뒤에 알림 문구를 목소리로 읽어 줍니다.
- 반복 알림과 한 번 알림도 바에 남은 시간 칸으로 보입니다.
- 떼어 낸 알림 묶음을 오른쪽 클릭하면 세로로 놓을 수 있습니다.
- 예전 알림 소리 4가지를 **(구) 띵동**, **(구) 띠링**, **(구) 띵 띵**, **(구) 삐빅**으로 다시 넣었습니다.

**1.2.0** (2026.11.19) · 알림 스위치 · 최근 검색 목록
- 바의 설정 버튼 왼쪽에 종 모양 스위치가 생겼습니다. 누르면 알림을 모두 끄고, 다시 누르면 켭니다.
- 검색칸을 누르면 아래에 최근 검색한 닉네임이 펼쳐집니다. 화살표로 고르고 Enter로 바로 검색할 수 있습니다.
- 목록의 ☆을 누르면 별표 캐릭터가 되어, 검색칸이 비어 있을 때 기본으로 불러옵니다.
- 다크 모드에서 메뉴와 목록에 마우스를 올렸을 때 칸 색을 차분한 회색으로 바꿨습니다.

**1.1.9** (2026.11.19) · 알림 소리 30가지 · 알림 떼어 두기
- 알림 소리가 30가지로 늘었고, 소리마다 2~3초 동안 울려서 놓치기 어렵습니다.
- 알림창의 **알림마다 소리 → 고르기**에서 야누스, 룬, 버프 등 알림마다 소리를 따로 고를 수 있습니다.
- 바의 남은 시간 칸을 끌어서 떼어 내 화면 아무 곳에나 둘 수 있습니다. 바에 다시 놓으면 제자리로 붙습니다.
- 바를 숨길 때 떼어 낸 알림도 같이 숨길지 프로그램 설정에서 고를 수 있습니다.
- 알림이 울릴 때 화면에 알림 이름을 띄울지 고를 수 있습니다.

**1.1.81** (2026.11.19) · 야누스 시간 맞추기
- 야누스 키를 잘못 눌렀을 때 바의 야누스 칸을 누르고 다시 깔면 바로 시간이 맞춰집니다.

**1.1.8** (2026.11.18) · 설정 관리 · Shift 키 다듬기
- 오른쪽 클릭 메뉴의 **설정 관리**에서 알림 설정과 프리셋을 이름과 비밀번호로 저장하고, 다른 PC에서 불러올 수 있습니다.
- 저장한 설정은 30일 동안 보관되고, 30일씩 연장할 수 있습니다. 저장과 불러오기는 하루에 3번씩 할 수 있습니다.
- 설정 리스트에서 저장한 설정과 불러온 설정, 지워지는 날을 볼 수 있습니다.
- 알림 키를 Shift로 정하면 왼쪽·오른쪽 Shift 둘 다 알림 키로 셉니다.

**1.1.72** (2026.11.17) · 알림 15칸 · 회수 알림 없앰 · 안정성 다듬기
- 반복 알림과 단일 알림을 15칸까지 쓸 수 있습니다.
- 아이템 회수 알림을 없앴습니다.
- Ctrl+Alt+M으로 바를 숨기면 시계도 같이 숨습니다.
- 앱이 꺼지거나 켜지지 않던 몇 가지 경우를 고치고, 오래 켜 둬도 메모리가 덜 쌓이게 다듬었습니다.
- 업데이트 파일을 받을 때 주소와 크기를 더 꼼꼼히 확인합니다.

**1.1.71** (2026.11.17) · 받기 쉬운 설치 파일 · 프리셋 화면 고침
- 처음 설치할 때 받는 파일이 늘 같은 작은 설치 파일(`MapleBar-Setup.exe`)이 됩니다. 켜면 최신 버전을 받아 설치합니다.
- 알림 프리셋을 불러올 때 창이 움직이던 문제를 고쳤습니다.

**1.1.7** (2026.11.16) · 계산기 · 메모 · 알림 프리셋
- 바의 **도구** 메뉴(예전 AI)에 계산기와 메모를 넣었습니다.
- 계산기: 기록 저장·불러오기, 식과 변수를 넣으면 바로 계산하는 스크립트.
- 메모: 스티커 메모처럼 쓰고 페이지를 추가할 수 있습니다.
- 알림 설정을 프리셋으로 저장하고, 반복 알림과 한 번 알림을 3칸씩 넘겨 봅니다.
- 전체 알림 켜기·끄기. 끄면 바에 OFF가 뜨고, 누르면 다시 켜집니다.

더 지난 버전은 [패치 노트](https://choimy0204.github.io/maplebar/)에서 볼 수 있습니다.

## 주요 기능

**알림**
- 룬, 솔 야누스 시간을 화면 가운데와 바의 타이머 칸으로 알려 줍니다.
- 버프·도핑 알림, 정한 주기마다 반복하는 알림, 조합 키, 알림 띄울 모니터를 정할 수 있습니다.
- 버프가 도는 동안 정령의 펜던트를 꼈는지 확인해 줍니다.
- 메이플 창에서 누른 키만 읽습니다. 게임에는 아무것도 보내지 않습니다.

**사이트를 게임 위 창으로**
- 캐릭터 이름을 검색하면 환산 주스탯 같은 캐릭터 정보가 바로 열립니다.
- 경매장: 찾기, 검색 결과 저장, [착용 해보기]로 보스 배율 효율표 보기.
- 헥사 강화 계산기, 코디, 인벤, 네이버 웹툰, 유튜브·쇼츠, 실시간 방송.
- 주소를 직접 넣는 웹 창, 뒤로·앞으로 가기, 투명도 조절.
- 창은 메뉴마다 닫은 자리에서 다시 열립니다.

**그 밖에**
- 메이플 BGM 듣기, 인벤 자유게시판 새 글 알림, 자기계발 카드.
- 바 메뉴를 끌어서 순서 바꾸기, 메이플 창 크기 따라가기, 다크 모드.

## 직접 빌드

.NET 10 SDK와 Inno Setup 6이 필요합니다.

```
dotnet publish MapleBar.csproj -c Release -r win-x64 --self-contained true -o publish
ISCC installer\MapleBar.iss
```

받기용 설치기(`MapleBar-Setup.exe`)는 `bootstrap` 폴더에서 따로 만듭니다. 늘 같은 파일이 나오도록 .NET SDK 10.0.404로 고정해 두었습니다.

```
cd bootstrap
dotnet build -c Release -o out
```

태그(`v버전`)를 올리면 GitHub Actions가 설치 파일을 만들어 Releases에 올립니다.
